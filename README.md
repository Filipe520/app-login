# 📱 App Auth Flow (React Native)

Um projeto inicial de fluxo de autenticação desenvolvido em **React Native**, focado em construir interfaces limpas, modernas e funcionais para telas de **Login** e **Cadastro**.

> _"Todo grande projeto começa com passos simples. Um passo de cada vez até andar com as próprias pernas."_ 🚀

---

## 🛠️ Tecnologias Utilizadas

- **React Native** (com TypeScript)
- **Expo** / **React Native CLI**
- **React Navigation** (Navegação entre telas)
- **Styled Components** / **StyleSheet**

---

## 📱 Telas do Projeto

### 1. Tela de Login (`Entrar`)

- Campo de E-mail e Senha.
- Navegação direta entre inputs com tecla Enter/Próximo (`useRef` + `onSubmitEditing`).
- Link direto para a tela de cadastro.

### 2. Tela de Cadastro (`Cadastrar`)

- Campos para Nome, E-mail, Senha e Confirmação de Senha.
- Layout responsivo adaptado para telas modernas (testado no Pixel 9 - Android 15 / API 35).
